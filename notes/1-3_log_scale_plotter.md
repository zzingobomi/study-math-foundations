### 빈칸 문제 (채팅에 낸 그대로)

**1. 작은 숫자로 먼저 확인**
```
log₁₀(1000 × 100) = log₁₀ 100000 = ___
log₁₀ 1000 + log₁₀ 100          = ___
```

**2. 일반 유도:** 두 수를 p = 10ᵐ, q = 10ᵏ라고 해요. 그러면 m = log₁₀ p, k = log₁₀ q예요.
```
p × q = 10ᵐ × 10ᵏ = 10^(___)        ← 지수 법칙
log₁₀(p × q) = ___ = log₁₀ p + log₁₀ q
```

**3.** 0.9ⁿ은 0.9를 n번 곱한 거예요. 2번 법칙을 계속 쓰면:
```
log₁₀(0.9ⁿ) = log₁₀ 0.9 + log₁₀ 0.9 + … (n번) = ___ × log₁₀ 0.9
```

**4.** log₁₀ 0.9 ≈ −0.046이에요. 모델 A의 loss에 로그를 씌우면:
```
log₁₀(1000 × 0.9ⁿ) = log₁₀ 1000 + log₁₀(0.9ⁿ) = ___ + n × (___)
```

### 이어서 할 계획 (Claude 메모)

- **빈칸 답:** 1) 5, 5 · 2) $m + k$, $m + k$ · 3) $n$ · 4) $3 + n \times (-0.046)$ → 1-1의 $y = ax + b$, 즉 직선이다. 기울기 $\log_{10} 0.9 \approx -0.046$, 절편 $3$. **그래서 모델 A는 로그 스케일에서 직선이다.**
- **이론 마무리:**
  - 코드로 확인: `np.diff(np.log10(loss_a))`가 전부 `np.log10(0.9)` ≈ −0.0458이다. 한 단계($\Delta x = 1$)마다 $\Delta y$가 같다 = 기울기가 일정하다 = 직선.
  - 132단계를 로그로 손으로: $3 - 0.0458n < -3$ → $n > 6 / 0.0458 \approx 131.1$ → 132단계.
  - B는 왜 직선이 아닌가: $\log(A + 0.1)$은 쪼갤 수 없다. 로그는 **곱**을 합으로 바꾸지, 합을 바꾸지 않는다 ($\log(p + q) \ne \log p + \log q$).
- **직접 구현 후보:** `mymath/logs.py`
  - `digits(n)`: 양의 정수의 자릿수 $= \lfloor \log_{10} n \rfloor + 1$. $n \le 0$이면 `ValueError` (로그는 양수에만 쓴다 — 1-1의 정의역). 기댓값은 `len(str(n))`. 아주 큰 수는 부동소수점 때문에 틀릴 수 있으니 $10^{15}$ 미만만 테스트한다.
  - `steps_to_reach(start, ratio, target)`: $\text{start} \times \text{ratio}^n \le \text{target}$이 되는 첫 $n$ ($0 < \text{ratio} < 1$). $n \ge \log(\text{target}/\text{start}) / \log(\text{ratio})$를 올림한다. $\log(\text{ratio}) < 0$이라 나눌 때 부등호가 뒤집히는 점을 힌트로 준다. 기댓값은 테스트 안에서 반복문으로 구한다. 경계에 딱 걸리는 값(1000, 0.1, 0.001 같은)은 부동소수점 때문에 피한다.
- **문제 후보:**
  - ★ 지수·로그 값 손계산 ($2^5 \times 2^3$, $10^{-2}$, $\log_{10} 10000$, $\log_{10} 0.001$, $16^{1/2}$)
  - ★★ 1-1 센서 raw 0~4095: $4096 = 2^?$ → 몇 비트 센서인가 ($\log_2 4096 = 12$) · 1-2: 가동률 99% 서버를 몇 대부터 이으면 서비스 가동률이 50% 밑으로 가나 ($n > \log 0.5 / \log 0.99 \approx 68.97$ → 69대) · $\log_{10} 2 \approx 0.301$로 $\log_{10} 8$, $\log_{10} 20$, $\log_{10} 5$

### 이론 ①~③

- **① 지수 법칙:** $a^n$은 $a$를 $n$번 곱한 것 ($a$는 밑, $n$은 지수). $a^m a^n = a^{m+n}$. 지수 자리에 변수가 있는 함수($1000 \times 0.9^n$)가 지수함수다. 밑이 1보다 크면 커지고, 1보다 작으면 작아진다. 학습자는 규칙을 이미 알고 있었다: "0제곱은 1이고 음수는 제곱이 분모가 되고 두개를 곱하면 지수끼리 더한다".
- **② 지수가 0·음수·분수일 때:** 따로 외우는 규칙이 아니라, 지수 법칙이 깨지지 않도록 정한 값이다.
  - $2^3 \times 2^0 = 2^3$이어야 하니까 $2^0 = 1$
  - $2^3 \times 2^{-3} = 2^0 = 1$이어야 하니까 $2^{-3} = 1/2^3 = 1/8$
  - $9^{1/2} \times 9^{1/2} = 9^1 = 9$이어야 하니까 $9^{1/2} = \sqrt{9} = 3$. 1-2의 $0.99^{1/5}$는 5번 곱해서 0.99가 되는 수였다. $8^{1/3} = 2$ 맞힘.
- **③ 로그 = 지수를 거꾸로:** $10^3 = 1000 \Leftrightarrow \log_{10} 1000 = 3$. $\log_{10} x$는 "10을 몇 번 곱해야 $x$가 되나". 1-1에서 raw → mm 식을 뒤집은 것처럼 $10^n$을 뒤집은 함수다.
  - $\log_{10} 100 = 2$, $\log_{10} 0.01 = -2$, $\log_{10} 1 = 0$ 맞힘
  - $\log_{10} 4095$는 3과 4 사이 맞힘 ($10^3 \le 4095 < 10^4$). 자릿수 = $\log_{10}$의 정수 부분 + 1 = 4자리
