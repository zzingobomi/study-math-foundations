## 한 줄 요약 (내 말로)

> a 는 기울기 b 는 x 가 0 일때 값인데 함수인지 아닌지도 중요하고 이걸 실제 상황에 대입할때는 이 함수가 정말 성립하는지? 이런거도 중요하게 봐야한다

## 핵심 정리

- **함수:** 입력 하나에 출력이 딱 하나 나오는 규칙. $f : X \to Y$는 코드의 타입 시그니처 `def f(x: X) -> Y`와 같다.
- **정의역:** 넣어도 되는 값 전체 (센서: 0~4095). **치역:** 실제로 나오는 값 전체 (50~459.5mm).
- **기울기** $a = \dfrac{\Delta y}{\Delta x}$: $x$가 1 늘 때 $y$가 느는 양. 직선은 어디서 재도 같다.
- **y절편** $b$: $x = 0$일 때의 $y$. AI의 $wx + b$에서 편향(bias)이라고 부르는 것.
- **유도 — 두 점을 지나는 직선:**
  - $a = \dfrac{y_2 - y_1}{x_2 - x_1}$ (단, $x_1 \ne x_2$)
  - 직선이 $(x_1, y_1)$을 지나므로 $y_1 = a x_1 + b$ → 이항해서 $b = y_1 - a x_1$
  - 같은 식을 $y = a(x - x_1) + y_1$로 쓰면 "출발점에서 기울기 $a$로 간다" (4-6에서 다시 나온다)
- **오늘의 센서:** $\text{mm} = 0.1 \cdot \text{raw} + 50$. raw가 1 늘 때마다 0.1mm씩 늘고, raw 0은 50mm (센서가 재기 시작하는 거리)다.
- **직접 구현:** `mymath/line.py`의 `slope`, `line_through`. `line_through`가 `slope`를 다시 써서 세로선 검사가 두 함수에 모두 걸린다.
- **빼는 순서:** 분자와 분모를 **같이** 뒤집으면 값이 같다.
  $$\frac{y_1 - y_2}{x_1 - x_2} = \frac{-(y_2 - y_1)}{-(x_2 - x_1)} = \frac{y_2 - y_1}{x_2 - x_1}$$
  한쪽만 뒤집으면 부호가 바뀌어서, 올라가는 직선이 내려가는 직선으로 나온다. 기울기의 부호는 방향이다 (+ 올라감, − 내려감).
- **단위:** 기울기의 단위 = $y$의 단위 ÷ $x$의 단위 (cm/s, %/분). 절편의 단위 = $y$의 단위.
- **음수 절편:** 컨베이어 $y = 30t - 30$에서 $b = -30$cm는 0초에 상자가 기준선에 도착하기 30cm 전이었다는 뜻이다.
- **정의역은 식이 아니라 상황이 정한다:** 배터리 $y = -0.4t + 96$은 어떤 $t$든 받아 준다 ($t = 300$이면 $-24\%$). 배터리는 0~100%여야 하므로 $-10 \le t \le 240$이고, 시계를 켜기 전에 무슨 일이 있었는지 모르면 $0 \le t \le 240$으로 잡는다.
- **외삽:** 잰 범위(10분, 40분) 밖으로 직선을 늘려 예측하는 것. 그 밖에서도 직선이 성립한다는 보장은 없다. AI 모델이 학습 데이터 범위 밖에서 틀리기 쉬운 것도 같은 이유다.
- **거꾸로 가는 식:** $y = ax + b$를 $x$에 대해 풀면
  $$x = \frac{y - b}{a} \quad (a \ne 0)$$
  센서는 $\text{raw} = 10(\text{mm} - 50) = 10 \cdot \text{mm} - 500$. 300mm에서 멈추려면 raw 2500에서 멈춘다. 기울기 0.1과 10은 역수다 ($0.1 \times 10 = 1$). 같은 변화를 $\dfrac{\Delta \text{mm}}{\Delta \text{raw}}$와 $\dfrac{\Delta \text{raw}}{\Delta \text{mm}}$로 분자·분모만 바꿔 본 것이기 때문이다.
- **$a = 0$이면 거꾸로 갈 수 없다:** $y = b$인 가로선은 $x$가 무엇이든 $y$가 같아서 $y$만 보고 $x$를 알 수 없다. 입력 하나에 출력이 무한히 많으니 거꾸로 가는 식은 함수가 아니다. $x$축과 $y$축을 맞바꾸면 가로선은 세로선이 된다. 기울기 0을 뒤집은 $1/0$이 깨지는 것과 같은 이야기다.
- **세 점이 한 직선 위에 있나:** 한 직선 위라면 어느 두 점으로 재도 기울기가 같다. (1000, 150), (3000, 350), (2500, 310)은 두 점씩 재면 0.1, 약 0.107, 0.08로 달라서 한 직선 위에 있지 않다. 앞의 두 점이 맞다면 세 번째 값은 10mm 튀었다. 여러 점을 가장 잘 지나는 직선은 6-1(최소제곱)에서 구한다.

## 헷갈렸던 점

- raw = 0이면 0mm라고 예측했다 → 실제는 50mm. 직선이 원점을 지나지 않을 수 있다 (y절편).
- $x_1 = x_2$일 때 선이 x축과 평행하다고 답했다 → 실제는 **y축과 평행한 세로선**이다. 입력 하나에 출력이 여러 개라 함수가 아니고, 그래서 공식이 0으로 나누기에서 깨진다. x축과 평행한 가로선은 $y_1 = y_2$일 때이고, 기울기가 0인 멀쩡한 함수다.
- 빼는 순서를 바꿔도 기울기가 같은 이유를 "어차피 둘의 차이라서"라고 답했다 → 차이는 순서를 바꾸면 부호가 뒤집힌다. 분자와 분모가 **둘 다** 뒤집혀서 −를 −로 나누니까 같아지는 것이다.
- 거꾸로 가는 식을 $x = y - b / a$라고 썼다 → $x = (y - b) / a$. 괄호가 없으면 $b / a$부터 계산한다 (파이썬도 같다).
- 배터리 식에 $y = 100$을 넣었더니 $t = -10$이 나와서 무슨 뜻인지 물었다 → 음수 시간은 시계를 켜기 전이다. 그때도 같은 식이 성립했는지는 식이 모른다. 그래서 정의역은 상황을 보고 정한다.
